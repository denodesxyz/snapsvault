# Feedback

This page says where to send feedback, questions and reports about SnapsVault, so a message reaches the right place the first time.

## Where to go

| I want to | Go to |
|---|---|
| Ask a question or get help | [Telegram](https://t.me/goldzn) or email [hello@denodes.io](mailto:hello@denodes.io) |
| Give feedback or suggest a feature | [GitHub issues](https://github.com/denodesxyz/snapsvault/issues/new/choose) |
| Report a bug in the Marketplace, the SnapsOS CLI, the REST API or these docs | [GitHub issues](https://github.com/denodesxyz/snapsvault/issues/new/choose) |
| Report a problem with a listing or a feed file | [Registry issues](https://github.com/denodesxyz/snapsvault-registry/issues) |
| Report a security issue | See [Report a security issue](#report-a-security-issue). Do not open a public issue. |

## Give feedback and get support

Questions about how SnapsVault works, ideas and general feedback go to the SnapsVault team on [Telegram](https://t.me/goldzn) or by email at [hello@denodes.io](mailto:hello@denodes.io). A concrete feature request is best as a [GitHub issue](https://github.com/denodesxyz/snapsvault/issues/new/choose), because the discussion stays next to the code.

## Report a bug

Open an issue in the [SnapsVault repository](https://github.com/denodesxyz/snapsvault/issues/new/choose) and pick the bug template. Search existing issues first. [Improvements](/contributing/contribute#issues) lists what a good report contains.

## Report a listing problem

A wrong value on a snapshot, a snapshot that does not appear, or a problem with a contributor's feed or registry file goes to the [registry issues](https://github.com/denodesxyz/snapsvault-registry/issues). Name the contributor, the chain ID and the feed URL.

A problem with a contributor's server or a snapshot file that does not download is best reported to that contributor. Its contact details are on its snapshot page in the [Marketplace](/core-components/marketplace#snapshot-page).

## Report a security issue

::: warning Keep it private
Do not report security problems in public issues, pull requests or discussions.
:::

Use GitHub private vulnerability reporting on the [SnapsVault repository](https://github.com/denodesxyz/snapsvault/security/policy) (Security tab, "Report a vulnerability"), or email [hello@denodes.io](mailto:hello@denodes.io). The process and the scope are in [SECURITY.md](https://github.com/denodesxyz/snapsvault/blob/main/SECURITY.md).
